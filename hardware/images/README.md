# Hardware Design Images

This folder contains visual evidence of the Postura hardware design.

## Schematic Overview

`schematic-overview.png`

The schematic shows the electrical architecture and interconnection of the major hardware blocks, including the ESP32, MPU6050 IMU, power-management circuitry, USB interface, indicators, and supporting components.

## PCB Layout

`pcb-layout.png`

The PCB layout shows the component placement and board-level design of the Postura hardware in KiCad.

These images are provided as visual evidence alongside the original KiCad schematic and PCB design files.
